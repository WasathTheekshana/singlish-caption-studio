Step 2: ElevenLabs account

Captions are made by ElevenLabs, which turns speech into text. You need your own account and key. You pay ElevenLabs directly for what you use.

  1. Create an account at elevenlabs.io.
  2. Open Settings, then API Keys and create a key.
  3. Allow only “Speech to Text” and set a credit limit, so the key can do nothing else.
  4. Paste the key below.

Stored in Windows Credential Manager on this PC and sent only to ElevenLabs. It is never shown again.

      Singlish Caption Studio

      Captions for videos where Sinhala and English are mixed in the same sentence. It writes them straight into your CapCut project and gives each language its own font and size.

      Made by

      Wasath. I make videos in Sinhala with a lot of English words in them, and I got tired of fixing captions by hand. This is the tool I wanted, shared in case it helps you too.

      Privacy

      The audio of the clips you pick is sent to ElevenLabs to be turned into text. Nothing else leaves your computer. Your key stays in Windows Credential Manager. There is no tracking and no account.

      Updates

      Checks GitHub for a newer version. Nothing is installed until you press Update.
